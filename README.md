# Budget Tracker Icon

Minimal blue-and-black icon asset for the Budget Tracker project.

## Files
- `icon.png` — 512 × 512 PNG app icon
- `favicon.ico` — favicon for browser tabs

## Use in an HTML app

Place these files in the same folder as your `index.html`, then add this inside the HTML `<head>`:

```html
<link rel="icon" href="favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="512x512" href="icon.png">
<link rel="apple-touch-icon" href="icon.png">
```

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload the files in this folder.
3. Commit the files.
4. If this is a standalone asset repository, the files can be used directly by your app through the repository's raw file URL or GitHub Pages URL.
